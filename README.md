# 70% keyboard

A low profile sleek 70% keyboard.


![Version](https://img.shields.io/badge/Version-1-blue)

## Features
- **Hot Swappable**: Swap existing switches easily without needing to solder
- **LED**: Supports independently controlled RGB backlighting for each switch
- **Multi-Layered**: Work between multiple different layers for increased macros and switch options
- **TFT Screen**: A powerful and sharp TFT display 
- **Raspberry Pi**: Fast and dynamic microcontroller allowing for easy software customization
- **Rotary Encoder**: Easy to use knob for changing granular control such as volume, brightness etc
